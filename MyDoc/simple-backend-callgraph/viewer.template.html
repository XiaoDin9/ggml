逐层展开，或阅读一条完整调用链

  • 节点上的「＋ N 个调用」展开下一层；「− 收起」隐藏整个子树。同名函数在不同分支中独立操作。
  • 「再展开一层」对所有可见末端各展开一层。「收起分支」操作选中节点；「全部收起」回到入口。
  • 选择预设后点击「打开整条链」，只展示 main 到目标的一条最短调用路径，包含全部中间函数。点击「返回调用树」恢复旁支。
  • 任意图中函数都可通过右侧「main → 此函数」打开完整链。搜索会自动展开祖先，让目标出现在树上。
  • 单击节点或连线查看完整源码。双击或点击「VS Code 打开实现」定位本地文件与行号。源码内函数名、右侧被调函数均可点击。
  • 「导出 SVG」保存当前展开状态的静态矢量图，保留源码链接。目录中的 callgraph.svg 也能折叠，需作为独立文件在浏览器中打开。

这是一张主要 ggml 调用树，具体展开 CPU 实现。条件路径不保证本次执行；Pass 1～5 是函数内部源码块。共享函数按分支复制显示，减少跨分支交叉连线；递归显示到回到祖先的节点为止。
