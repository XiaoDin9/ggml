# simple-backend：可折叠调用树与完整调用链

双击同目录下的 [index.html](index.html)，用浏览器打开。它是完全离线的单文件交互图，已嵌入函数实现，无需服务器或安装依赖。

- **逐层打开**：点击 main 节点上的「＋ N 个调用」，再点击 init_model、build_graph、compute 等节点上的加号，继续展开下一层。每个节点均可独立展开；「− 收起」隐藏它的整个子树。
- **完整调用链**：顶部选择 CPU 矩阵乘法、Pass 2、设备注册、内存分配或输出读取，点击「打开整条链」。图中仅保留 main 到目标的一条最短调用路径，包含全部中间函数。「返回调用树」恢复旁支并保留沿途展开状态。
- **任意目标**：搜索后自动展开到目标；选中图中任意函数，再点击右侧「main → 此函数」，即可单独显示它的完整链。
- **整层和分支**：「再展开一层」让所有可见末端向下展开一层；「收起分支」折叠当前选中的节点；「全部收起」回到入口。共享函数会在不同调用分支分别显示，互不影响；递归回到祖先时停止展开。
- **点击函数节点**：右侧显示该函数的完整源码与原文件行号。源码中带下划线的函数名也可点击并沿该分支展开。
- **点击连线**：显示被调用函数的实现，并提供调用处、实现处和 CPU 接口绑定位置。
- **进入 VS Code**：点击「VS Code 打开实现」，或双击函数/连线。勾选「点击时同时在 VS Code 打开实现」后，单击节点或连线就能同步定位。浏览器首次使用 `vscode://` 可能要求允许打开编辑器。
- **平移和缩放**：拖动画布、滚动鼠标滚轮；「适配」显示当前已展开的整棵树，「定位到树」放大到选中函数。
- **切换入口**：main、后端初始化、注册与设备、构建计算图、调度与分配、CPU 实现、数据读写与释放、切图 Pass 1～5。每个入口均可继续跨阶段展开，不受固定视图层数限制。
- **搜索**：按函数名、文件名或图中函数的中文用途查找。搜索还包含已索引文件中未绘入图的辅助实现。

**SVG 也可以折叠**：在浏览器中独立打开 [callgraph.svg](callgraph.svg)，使用节点上的加减号、顶部「再展开一层 / 全部收起 / CPU 乘法完整链」。函数名称与连线保留 VS Code 源码链接。通过 Markdown 或图片标签嵌入 SVG 时，查看器可能禁用脚本，此时使用 HTML 或直接在浏览器打开 SVG。

HTML 的「导出 SVG」会保存当前展开状态的静态图，适合插入文档；导出图也保留源码链接。共享函数按各条调用分支重复显示，树的连线只连接父子，避免跨分支交叉。

## 图的含义与范围

入口为 `examples/simple/simple-backend.cpp` 中的 `main`。main 直接调用的项目内函数全部纳入图，重点展开后端注册、设备选择、调度器、图构建、内存分配与 CPU 的 MUL_MAT 执行路径。标准库、平台辅助和各算子的全部优化内核没有继续绘制。

实线表示直接调用；紫色虚线表示已对照 CPU 接口表的函数指针分派；黄色虚线表示首次局部 static 初始化或函数内部阶段。`Pass 1～5` 是同一函数内按编号执行的源码块，不是独立函数；展开后还可以阅读该阶段内调用的辅助函数。

这是源码阅读图，不是本次运行的跟踪记录。条件连线和 CPU 回调表示可能路径：实际执行取决于编译选项、选中的设备、张量位置和调度器状态。`init_best` 可以选择 GPU / IGPU；本图将具体实现展开到 CPU。当前示例 `parallel=false`，且先显式 `alloc_graph`，后续 compute 的自动分配分支通常不再执行。

## 更新源码与行号

在项目根目录执行：

```powershell
python MyDoc/simple-backend-callgraph/generate.py
```

生成器仅使用 Python 标准库。函数清单与说明经过整理；函数定义、源码全文、直接调用位置、CPU 接口绑定与行号从当前工作区读取。它会校验 main 的直接项目调用是否遗漏，并检查各节点和跳转位置。

修改源码、移动项目或更换机器后重新生成。HTML 内嵌的是生成时快照，VS Code 链接则打开实际本地文件。

文件：`generate.py` 为生成器；`tree.js` 为 HTML 与 SVG 共用的调用树、递归检测和路径查找逻辑；`viewer.js`、`viewer.template.html` 与 `svg.template.svg` 为界面模板；`index.html` 与 `callgraph.svg` 为可单独打开的生成结果。生成器不会修改 ggml 源文件。
